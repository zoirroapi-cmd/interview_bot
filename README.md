# Interview Bot

Telegram-бот для подготовки к собеседованию по DevOps. Отвечаешь на вопросы **своими словами**, а ИИ проверяет ответ по эталонным тезисам и показывает, что раскрыто, что упущено, а где сказана неправда.

Пет-проект: Python, PostgreSQL, Docker Compose, LLM (GigaChat).

## Что умеет

- **Меню:** выбрать тему (случайный вопрос или список по порядку), случайный режим, повторение уже пройденного.
- **Проверка свободного ответа:** разбор по каждому тезису с цитатой из твоего ответа.
- **Интервальное повторение:** срок следующего повтора зависит от оценки.
- **Геймификация:** XP, серия дней (streak), дневная цель и плашка «сегодня N из M вопросов».
- **Напоминания:** раз в день в выбранное время, если цель дня ещё не выполнена.

## Как работает проверка

1. Для каждого вопроса хранятся 3-5 коротких эталонных тезисов. Их один раз генерирует модель и сохраняет в базу.
2. Ты пишешь ответ в свободной форме.
3. Модель для **каждого тезиса** возвращает цитату из ответа и статус:

| Статус | Баллы | Значение |
|---|---|---|
| `covered` | +1 | тезис раскрыт |
| `partial` | +0,5 | раскрыт частично или расплывчато |
| `missing` | 0 | в ответе об этом нет |
| `contradicted` | -1 | сказано обратное, неправда весит больше пропуска |

4. **Оценку 0-10 считает код, а не модель**: сумма баллов делится на число тезисов.
5. По оценке выставляется уверенность 1-5, от неё зависит срок повтора: 1-2 завтра, 3 через 3 дня, 4 через 7, 5 через 14.

Если цитаты нет в тексте ответа, статус тезиса сбрасывается в `missing`.

## Ограничения

- Проверка цитаты только убеждается, что она есть в ответе. Что цитата подтверждает именно этот тезис, проверяет модель, и лёгкая модель иногда ошибается и завышает оценку.
- Тезисы генерирует модель, вручную они не проверены. Неверный тезис даёт неверный разбор.
- Состояние диалога хранится в памяти: после перезапуска бота нужно открыть меню заново.
- Миграции: `init.sql` для чистой базы и несколько `ALTER TABLE ... IF NOT EXISTS` при старте, Alembic пока нет.
- Проверка TLS-сертификата GigaChat по умолчанию выключена (`GIGACHAT_VERIFY_SSL=false`), пока корневой сертификат не добавлен в образ.

## Структура

```
app/
  main.py      меню, обработчики Telegram, напоминания
  llm.py       клиент GigaChat, промпты, разбор ответа модели, подсчёт оценки
  db.py        запросы к PostgreSQL и мини-миграции
  config.py    конфигурация
scripts/
  import_questions.py        импорт вопросов из CSV
  generate_all_keypoints.py  генерация тезисов для всех вопросов
tests/
  test_llm.py  тесты разбора ответа модели
data/          CSV с вопросами (свои файлы не коммитятся, пример: questions.example.csv)
init.sql       схема базы
docker-compose.yml, Dockerfile, requirements.txt
```

## База данных

| Таблица | Назначение |
|---|---|
| `topics` | темы |
| `questions` | текст, приоритет, эталонные тезисы |
| `users` | XP, серия дней, дневная цель, время напоминания |
| `user_progress` | уверенность, интервал, `next_review_at` |
| `attempts` | история ответов, разбор ИИ, оценка |

## Быстрый старт

```bash
cp .env.example .env
# заполнить BOT_TOKEN, POSTGRES_PASSWORD (тот же пароль в DATABASE_URL), GIGACHAT_AUTH_KEY

# положить вопросы в data/questions.csv (формат ниже), затем:
docker compose up -d db
docker compose run --rm bot python -m scripts.import_questions /data/questions.csv
docker compose up -d --build bot
docker compose logs -f bot
```

Повторный импорт безопасен: вопрос с той же темой и текстом не дублируется. Порядок «по порядку» в боте определяется порядком импорта.

Если Telegram недоступен с сервера напрямую, бот можно пустить через прокси, настройки см. в `.env.example`.

### Формат CSV

Колонки `Тема` и `Вопрос` обязательны, приоритет берётся из текста вида `Приоритет 1 — ...` в любой колонке (по умолчанию 2). Пример: `data/questions.example.csv`.

### Переменные окружения

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB` | база |
| `DATABASE_URL` | строка подключения (хост `db`) |
| `GIGACHAT_AUTH_KEY` | ключ авторизации GigaChat |
| `GIGACHAT_MODEL` | модель, по умолчанию `GigaChat-2` |
| `GIGACHAT_VERIFY_SSL` | `true` включает проверку сертификата |
| `BOT_TZ` | часовой пояс, по умолчанию `Europe/Moscow` |
